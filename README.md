A single one-line joke about cats (under 200 characters) for the
[make.fun bounty "The One-Line Cat Joke That Lands"](https://make.fun/bounty/u-aldy998-the-one-line-cat-joke-that-lands-a7b18262).

`main.ts` writes the joke to `/output/entry.txt` — one line, nothing else —
after checking it against the gate (1–200 characters, a single line, about
a cat). Run it with `node main.ts`. The output is deterministic: two runs
produce byte-identical files.

The joke:

> My cat doesn't knock things off the table to be rude — she's quality control, and so far everything I own has failed inspection.
